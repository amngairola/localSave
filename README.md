# LocalSave – Local Clipboard & Snippet Manager

LocalSave is a lightweight, privacy-focused clipboard and snippet manager that lets you quickly save, organize, search, and copy temporary text or code snippets directly in your browser.

No account, login, backend, or cloud storage required. Everything stays locally in your browser.

## Features

- **No Authentication Required:** Start saving snippets instantly without creating an account.
- **Local Storage:** All snippets are stored locally in your browser. No server or cloud database is involved.
- **Privacy First:** Your saved data never leaves your browser.
- **Quick Save:** Easily save copied text, code snippets, notes, commands, and other temporary information.
- **Real-Time Search:** Instantly find saved snippets by searching their titles or content.
- **One-Click Copy:** Quickly copy any saved snippet to your clipboard.
- **Keyboard Shortcuts:** Navigate, search, and copy snippets efficiently without relying on the mouse.
- **JSON Import & Export:** Back up your snippets or transfer your data between browsers and devices.
- **Clean Interface:** A simple, lightweight, and intuitive UI designed for productivity.

## Getting Started

### Prerequisites

You need Node.js and npm installed on your system.

### Installation

```bash
# Clone the repository
git clone <your-repository-url>

# Navigate to the project directory
cd <repository-name>

# Install dependencies
npm install

# Start the development server
npm run dev
```

## How It Works

1. Open LocalSave in your browser.
2. Paste or enter any text, code, command, or note you want to save.
3. Save it as a snippet for quick access later.
4. Use real-time search to find previously saved content.
5. Copy snippets instantly whenever needed.
6. Export your snippets as JSON to create a backup or import them into another browser.

## Data & Privacy

LocalSave is designed around local-first data storage.

- No login or signup.
- No backend or database.
- No cloud synchronization.
- No external data storage.
- Snippets remain in the browser where they were saved.

**Note:** Clearing browser storage or site data may permanently delete your saved snippets. Export your data regularly to keep a backup.
